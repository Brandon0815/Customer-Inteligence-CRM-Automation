# Customer Intelligence CRM Automation

Automated CRM pipeline built with Make.com, the Etsy API, and Google Sheets for customer deduplication, purchase tracking, and customer lifetime value analysis.

## Problem

E-commerce stores generate large amounts of order data but often lack a convenient way to track repeat customers and maintain CRM functionality.

## Solution

Built a CRM automation workflow using Etsy, Make.com, and Google Sheets that:

* Imports customer data
* Cleans and normalizes data
* Deduplicates customers
* Tracks purchase history
* Calculates customer lifetime value
* Identifies repeat buyers

## Tech Stack

* Etsy API
* Make.com
* Google Sheets

## Features

* Email validation
* Email normalization
* Customer deduplication
* Purchase count tracking
* Customer lifetime value tracking
* Automated CRM updates

## Results

* Processed 390 historical Etsy orders
* Identified repeat customers automatically
* Built a clean CRM database
* Calculated customer lifetime value for each customer
* Eliminated duplicate customer records through automated deduplication

## Privacy Notice

All customer information displayed in screenshots, demos, and portfolio materials has been anonymized. Real customer names, email addresses, order IDs, and other personally identifiable information are not publicly shared.
