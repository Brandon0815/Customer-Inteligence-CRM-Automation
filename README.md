# Customer-Inteligence-CRM-Automation
Automated CRM pipline built with Make.com, Etsy EPI, and Google Sheets for customer deduplication, purchase tracking, and lifetime order total 

# Problem 
E-commerce stores generate order data but fail to conveniently track repeat customers and lack CRM components. 

# Solution 
Built a CRM automation scenario using Etsy, Make.com, and google sheets that:
- Imports customers data 
- Cleans and normalizes data
- Deduplicated customers
- Tracks purchase history 
- Calculates customers lifetime order total 
- Identifies repeat buyers 

# Stack 
- Etsy API 
- Make.com 
- Google Sheets

# Features
- Email validation
- Email normalization
- Customer deduplication
- Purchase count tracking
- Lifetime spend tracking
- Automated CRM updates

# Results
- Processed 390 historical Etsy orders
- Identified repeat customers
- Built a clean CRM database
- Calculated customer lifetime value automatically
